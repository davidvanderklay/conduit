Restore the pre-rewrite tab proportions

The current bar is technically switching states, but the icons are doing too much of the visual work. The rewrite made the symbols larger and the glass shell shorter, so compact mode feels like a cramped bar with labels removed instead of the same comfortable navigation becoming compact.

Recommendation: keep the native Liquid Glass surface, but explicitly restore smaller tab symbols, a taller shell, and a stable inset around every item. Compact mode should remove labels and contract the shell, not scale the symbols up to fill the available height.

What changes

Smaller symbolsUse an explicit SF Symbol configuration around 24–25pt instead of letting the native item sizing dominate the pill.
Taller glass shellReturn the expanded bar to roughly 76–82pt and compact mode to roughly 58–64pt, with enough vertical breathing room for the icon.
Inset contentKeep 8–10pt of inner padding and a selected background that sits inside the outer glass edge. Icons should never touch the shell boundary.
One state transitionAnimate the outer width and height together. Do not independently scale the tab bar or its icons with transforms.

Implementation plan

  1. Keep the platform-owned glass path. Continue using the native iOS tab bar/container so the Liquid Glass material, hit testing, and system interaction remain platform-owned.
  2. Make item sizing explicit. Build each item image with a fixed SF Symbol configuration, regular or medium weight, around 24–25pt. Preserve the existing 4-tab order and selected accent color.
  3. Restore the shell geometry. Use a taller expanded frame and a moderately shorter compact frame. Keep the responsive width distinction, but add horizontal and vertical insets so the bar has visible glass around the content.
  4. Align the native bar to the host bounds. Keep the layout container that prevents UIKit’s intrinsic height from winning, but avoid clipping away the glass edge. The container should size the tab bar cleanly rather than crop an oversized tab bar.
  5. Make compact mode label-only. Compact mode changes item titles to nil and keeps icon size, weight, selected state, and tap target stable. It should not apply a scale transform to the whole bar.
  6. Use one transition transaction. Animate width, height, and label visibility as one state change. Ignore repeated bridge updates when the state has not changed, preserving the previous choppiness fix.

Acceptance checks

  • At the top of Home, the expanded bar is visibly taller than compact mode and has a clear glass margin around every icon.
  • After scrolling down, the pill contracts as one smooth surface. The symbols do not grow, jump, or move toward the outer edge.
  • Scrolling back up restores the expanded shell without changing selected state or tab order.
  • Home, Discover, Library, and Settings remain individually tappable on iPhone and iPad, including compact mode.
  • Classic navigation remains full width and does not inherit floating-mode margins.
  • History, profile settings, and other contextual screens keep their back affordance and do not regress because of the bar resize.
  • Verify at least iPhone portrait, iPad portrait, and iPad landscape, with reduced motion enabled as a sanity check.

Out of scope

This pass does not change destinations, profile menu behavior, search, or the Liquid Glass material itself. It is a proportion and transition correction focused on restoring the earlier navigation feel.
