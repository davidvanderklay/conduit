# Contribute to Conduit

Help with code, documentation, bug reports, or testing on your devices.
Start with the [contribution guide](https://github.com/davidvanderklay/conduit/blob/main/CONTRIBUTING.md)
for the PR workflow, design constraints, and licensing boundaries.

- [Good first issues](https://github.com/davidvanderklay/conduit/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22good%20first%20issue%22)
  have small, defined outcomes.
- [Help wanted](https://github.com/davidvanderklay/conduit/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22help%20wanted%22)
  includes broader work and platform testing.
- [Discussions](https://github.com/davidvanderklay/conduit/discussions) is the place
  for setup questions, early ideas, and device test results.
- [Issue forms](https://github.com/davidvanderklay/conduit/issues/new/choose) collect
  reproducible bugs and focused feature requests.

Use the [development guide](development.md) for web/server and desktop setup,
or [mobile and TV development](mobile-development.md) for native clients.
Read the [roadmap](roadmap.md) before proposing a larger feature.

Keep credentials and personal data out of reports and screenshots. Report
vulnerabilities privately through the [security policy](https://github.com/davidvanderklay/conduit/blob/main/SECURITY.md).
Project spaces follow the [code of conduct](https://github.com/davidvanderklay/conduit/blob/main/CODE_OF_CONDUCT.md).
