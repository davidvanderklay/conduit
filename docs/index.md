# Conduit

Conduit is a self-hosted film and television app built around Stremio-compatible
add-ons. The server synchronizes accounts, household profiles, libraries, and
watch progress. Clients fetch catalogs and media directly from add-ons and sources.

## Get started

- [Install Conduit](installation.md) on desktop, mobile, or Android TV and choose
  Stable or Nightly. Android TV support is very experimental.
- [Self-host with Docker](deployment.md#docker-compose-quick-start) using published
  server and web images.
- [Set up accounts](authentication.md) and save recovery codes.
- [Update your installation](updates.md) or [join a watch party](watch-parties.md).

## Build and contribute

Use the [development guide](development.md) for the repository setup, or
[mobile and TV development](mobile-development.md) for native toolchains.
[Releases](releases.md) explains packaging and publication;
[the roadmap](roadmap.md) covers current work and planned platforms.

Conduit is under active development. Keep profile exports and instance backups.
